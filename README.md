# Student ID Card Generator

A PHP, HTML, CSS, and JavaScript application for creating student ID card previews.

## Project structure

```text
student-id-generator/
├── index.php
├── generate.php
├── config/
│   └── database.php
├── assets/
│   ├── css/style.css
│   ├── js/app.js
│   └── images/.gitkeep
├── uploads/.gitkeep
├── .gitignore
└── README.md
```

## Development

Run locally using XAMPP or another PHP environment. Database integration will be added in a later step. Never commit real student data, credentials, or uploaded student photos.
